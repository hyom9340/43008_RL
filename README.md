# Reinforcement Learning Assignment 2 — original version

The first-version notebooks, scripts, dependencies, and setup notes are collected in [`original/`](original/). Their contents are unchanged; only their paths have moved.

Open this repository in VS Code, select the project's `.venv` Python interpreter, and run the notebooks from top to bottom. Install dependencies from `original/requirements.txt`; the AMD DirectML setup is in `original/GPU_AMD_DIRECTML_SETUP.md`.

Training outputs, model checkpoints, videos, local virtual environments, and submission ZIP files are excluded from Git. Keep those files locally or in a separate backup. The executed `.ipynb` files retain their cell outputs when saved.

The redesigned NVIDIA CUDA notebooks are developed separately on the `assignment2/cuda-notebook-redesign` branch.
