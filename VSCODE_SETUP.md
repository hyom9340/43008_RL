# VS Code setup

The project is configured to use `.venv\\Scripts\\python.exe`.

1. Open this folder in VS Code: `C:\\Users\\James\\Desktop\\RL`.
2. Install the recommended Microsoft Python and Jupyter extensions if prompted.
3. Open `Pendulum_TD_Q_Learning.ipynb`.
4. Click the kernel selector in the upper-right corner and choose `.venv\\Scripts\\python.exe`.
5. Choose **Restart** and then **Run All**.
6. Save the notebook after execution so all outputs remain embedded.

You can also press `Ctrl+Shift+P`, select **Tasks: Run Task**, and run
`RL: Run Pendulum notebook` to execute and save it automatically.

The generated video is located at:

`pendulum_artifacts\\videos\\pendulum-q-learning-episode-0.mp4`
